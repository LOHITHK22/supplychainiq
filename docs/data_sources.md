## FRED (Federal Reserve Bank of St. Louis) — primary market source

| Item | Value |
| --- | --- |
| Docs | https://fred.stlouisfed.org/docs/api/fred/ |
| Observations endpoint | `https://api.stlouisfed.org/fred/series/observations` |
| Metadata endpoint | `https://api.stlouisfed.org/fred/series` (`last_updated`, units, frequency) |
| Revisions | `realtime_start=1776-07-04&realtime_end=9999-12-31` returns every vintage |
| Auth | Free API key (32-char lowercase alphanumeric) |
| Rate limit | None published; terms require "reasonable" use. Client throttles to ≤ 2 requests/s and retries 429/5xx with exponential backoff |
| Terms | https://fred.stlouisfed.org/docs/api/terms_of_use.html — must display: "This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis." Series whose notes contain "Copyright" need the owner's permission beyond personal use |
| Missing values | Reported as `"."`, stored as `NULL` |

## U.S. Census Bureau — Monthly Retail Trade (MARTS) via Census Data API (Phase 2 extension)

| Item | Value |
| --- | --- |
| Endpoint | `https://api.census.gov/data/timeseries/eits/mrts` |
| Variables | `cell_value`, `data_type_code`, `category_code`, `seasonally_adj`, `time_slot_id`, `time` |
| Auth / limits | Key optional; 500 queries per IP per day without a key |
| Licence | U.S. government work, public domain |
| Use | Cross-check of FRED's nonstore retail series (NAICS 454) — to verify category code |
